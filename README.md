# AI 画布生图 · 素材中心

一个**零依赖、本地可跑的网页版 AI 生图工作台**：左侧「素材中心」把风格 / 排版 / 字体 / 配色 / 角色 / 上传图做成真实卡片，**拖进中间画布立刻看得见**，自动组装提示词，调生图接口出底图，再自由组合图层并导出。

> 设计目标：一看就会用、最简单的拖拉操作。区别于市面套壳工具，本项目的差异化在于 **真实字体文字层（根治中文乱码）+ 角色参考图一致性 + 可复刻配方文件 + 风格可自定义**。

---

## ✨ 功能

- **素材中心（六标签，张张带真图）**
  - 风格 / 排版：直接显示 handraw 仓库的**原图**（一张不漏），并**按大类筛选**（风格 9 类：国际社论幽默 / 经典绘本 / 现代平面 / 日本插画 / 新国风 / 3D黏土 / 动漫赛璐璐 / 先锋实验 / 写实摄影；排版 5 类：社媒卡 / 信息图 / 漫画分镜 / IP设计 / 电商），可拖拽
  - 字体：**13 款免费商用**（思源黑/宋、站酷快乐/小薇/庆科黄油、马善政楷书、刘建毛草、龙藏、志莽行书 + 系统字体），真实字体渲染样张，拖入画布生成文字层（双击改字）；**支持上传自定义字体**（.ttf/.otf/.woff/.woff2，自动注册）
  - 配色：色块 + 名称 + hex，拖入即铺底色
  - 角色：上传你自己的人物图，可传多张并**锁定一个主角**（参考图注入，尽量保证生成图同一人）
  - 我的图片：上传照片 / logo 自由组合
- **画布尺寸可自定义**：预设比例（3:4 / 1:1 / 16:9 / 9:16 / 4:3）之外，可选「自定义尺寸」自由输入宽高（64–4096px）
- **出图后端可插拔**
  - 演示模式（无需 Key，返回占位底图走通全流程）
  - OpenAI 兼容接口：豆包 / 火山引擎 Ark / WorkBuddy 等，填 Base URL + Key + 模型名即可出真图
- **设置中心（⚙）**
  - 出图后端配置
  - 图片上传压缩（最大边长 / 格式 PNG·JPEG·WebP / 质量）
  - 提示词（语言导向 / 是否含字体·角色说明 / 风格锚点前缀 / 通用后缀）
  - **自定义风格**：在「风格」页点「＋ 自定义风格」（或在设置中心）运行时添加任意风格（如 3D、像素、油画…），自动并入左侧「风格」可拖入
- **导出**：PNG / 配方 JSON / 配方 MD

## 🚀 快速开始

方式一（最简单）：直接用浏览器打开 `index.html`。

方式二（推荐，避免个别浏览器本地文件限制）：
```bash
cd ai-canvas
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/index.html
```

### 接真实出图
1. 点右上 `⚙ 设置` → 出图后端 → 模式选「OpenAI 兼容接口」
2. Base URL 填 `https://ark.cn-beijing.volces.com/api/v3`（火山引擎 Ark 的 OpenAI 兼容端点）
3. 填 Key 与模型名（如豆包的 seedream）
4. 回来点「⚡ 生成底图」即出真图

> 密钥只保存在本机浏览器 `localStorage`，不会上传到任何服务器。

## 📁 目录结构

```
ai-canvas/
├── index.html        # 页面结构（三栏 + 设置中心弹窗）
├── styles.css        # 玻璃拟态浅色主题
├── app.js            # 全部逻辑：素材中心、拖拽画布、提示词、出图、导出、设置
├── data.js           # 素材库：368 风格 + 170 排版 + 36 配色 + 8 字体（由 build_assets.py 生成）
├── build_assets.py   # 从 handraw 仓库抓取并打包原图 + 提示词到本地
└── assets/           # 574 张 webp 原图（风格/排版/配色），约 33MB
```

## ⚠️ 已知边界（诚实说明）

- **角色一致性非 100%**：参考图注入约 80–85% 一致性，依赖所选模型的参考能力，极端角度可能漂移。这是当前生图能力的物理上限，非 bug。
- `assets/` 为 33MB 二进制图片，已直接纳入 git；如需更干净的仓库历史，可改用 **Git LFS** 管理。
