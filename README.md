# AI 画布生图 · 素材中心

一个**零依赖、本地可跑的网页版 AI 生图工作台**：左侧「素材中心」把风格 / 排版 / 配色 / 角色 / 我的图片 / 字体做成真实卡片，**拖进中间画布立刻看得见**，自动组装提示词，调生图接口出底图，再自由组合图层、放进无限工作台排版，最后导出。

> 设计目标：一看就会用、最简单的拖拉操作。
> 差异化：**真实字体文字层（根治中文乱码）+ 角色参考图一致性 + 可复刻配方文件 + 风格可自定义 + 节点式无限工作台**。

---

## ✨ 功能

### 一句话出图（最省事）
顶栏写一句话（如「橘猫晒太阳的小红书封面」），自动配好**风格 / 排版 / 配色 / 画幅**，自动检测本地代理并直接生成；画布只留一张干净结果图。配合可编辑提示词、`Ctrl/Cmd+Z` 撤销、顶栏出图状态灯、素材搜索 / 收藏 / 最近使用。手动逐项选素材的旧流程完整保留。

### 素材中心（六标签，张张带真图）
顶部标签为 **风格 / 排版 / 配色 / 角色 / 我的 / 字体**，纯文字、`/` 分隔，当前标签底部一道靛蓝横线。每个标签都有独立的「▦ 全部」页面入口：

- **风格 / 排版**：显示 handraw 仓库原图（一张不漏），可拖拽、可搜索、可收藏。
  - 点「共 X 项 ▦ 全部」打开独立页，列出该类型**全部**条目；页内顶部带**分类 chips**，点一下即按类筛选（风格 9 类：国际社论幽默 / 经典绘本 / 现代平面 / 日本插画 / 新国风 / 3D黏土 / 动漫赛璐璐 / 先锋实验 / 写实摄影；排版 5 类：社媒卡 / 信息图 / 漫画分镜 / IP设计 / 电商）。
- **配色**：色块 + 名称 + hex，拖入即铺底色；「▦ 全部」以纯色卡网格展示全部 36 套配色。
- **角色**：上传你自己的人物图，可传多张并**锁定一个主角**（参考图注入，尽量保持同一人）；「▦ 全部」只列角色图。
- **我的**：上传照片 / logo / 素材，自由组合；「▦ 全部」只列我的图片（不再和角色图混排）。
- **字体**：12 款可免费获取的中文字体（思源黑/宋、霞鹜文楷、霞鹜文楷屏幕、MiSans、马善政楷书、刘建毛草、龙藏、志莽行书、站酷快乐/小薇/庆科黄油）+ 2 款系统字体（苹方 / 微软雅黑），真实字体渲染样张，拖入画布生成文字层（双击改字）；支持上传自定义字体（`.ttf/.otf/.woff/.woff2`，自动注册）。「▦ 全部」页里每款字体带 **「查看/下载 ↗」**，直达 fontsource.org / 官方 GitHub 等免费获取页（系统字体标注「系统内置」）。

### 最近使用
左栏「最近使用」记录你最近用过的素材（最多 8 条），**每条 chip 前面带类型标记 + 对应编号**，例如 `风 FA-038`、`排 SC-012`、`配 C-03`、`角 <名称>`、`字 <字体名>`，一眼看出它属于哪一类、是哪个编号；点一下即可再次加入画布。

### 节点式无限工作台
顶栏「⛶ 工作台」进入无限画布：多画板并排、自由缩放平移、自动保存。右侧「节点面板」提供 **提示词 / 图片 / 随机变量** 输入节点，**文生图 / 生成节点** 生成节点，**输出 / 便签** 结果节点，以及画板、分组框、批量循环、合并对比等组织节点；节点之间连线即可把提示词、参考图串起来生成。快捷键 `Ctrl/Cmd+Z` 撤销、`Delete` 删除、方向键微移。

### 场景模板 / 配方 / 变体
右栏 6 套场景模板（小红书封面、公众号头图、电商主图、信息图、手机壁纸、四格漫画）一键套整套配方；导出的配方 JSON / MD 可再导回来；设置里可选「一次出 2 / 4 张」，并排挑一张入画布，未选中的不占图层。

### 生成前参考图确认板
右栏逐张缩略图 + 勾选，看到的就是真会发给模型的，最多 4 张；非代理模式明确写「不会发送」。提示词只给比例（不写无用像素）、字体交给后期文字层、反向提示词与参考图条数明示。

### 画布尺寸可自定义
预设比例（3:4 / 1:1 / 16:9 / 9:16 / 4:3）之外，可选「自定义尺寸」自由输入宽高（64–4096px）。

### 出图后端可插拔
- **演示模式**：无需 Key，返回占位底图走通全流程（顶栏状态灯明确标注「演示占位图」）。
- **本地出图代理（推荐）**：免 CORS、Key 留在服务端、参考图真进模型。双击 `启动预览.command` 会一并启动；设置里选「本地代理」即可。
- **OpenAI 兼容接口**：豆包 / 火山引擎 Ark / WorkBuddy 等，填 Base URL + Key + 模型名即可出真图（浏览器直连可能有 CORS 预检问题）。
- **本地 ComfyUI**：预留 `server/workflows/` 模板，支持 `{{REF_IMAGE}}` 占位符接 IPAdapter / ControlNet（需自备工作流）。

### 设置中心（⚙）
出图后端配置（含一次出图张数）、图片上传压缩（最大边长 / 格式 / 质量）、提示词（语言导向 / 是否含字体·角色说明 / 风格锚点 / 通用后缀）、**自定义风格**（「＋ 自定义风格」运行时添加任意风格并并入左栏）。

### 导出 / 导入
PNG / 配方 JSON / 配方 MD，配方 JSON、MD 可再导入还原素材、画幅与文案。

## 🚀 快速开始

**方式一（最简单）**：双击 `启动预览.command`，一个脚本同时起网页服务（`8123`）和出图代理（`9004`）并打开 `http://localhost:8123/`；停止双击 `停止预览.command`，两个一起停。

> ⚠️ **不要用 `file://` 直接打开 `index.html`**：574 张图会一次性读盘导致首屏极慢，工作台的 IndexedDB 也可能不可用。

**方式二（命令行）**：
```bash
cd ai-canvas
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/
```

代理首次启动会自动生成 `server/config.json`（默认 `upstream: "mock"` 自检，不消耗积分；字段见 `server/config.example.json`）。只想单独控制代理时仍可用 `启动出图代理.command` / `停止出图代理.command`。

### 接真实出图
1. 点右上 `⚙ 设置` → 出图后端 → 模式选「OpenAI 兼容接口」（或「本地代理」）
2. Base URL 填 `https://ark.cn-beijing.volces.com/api/v3`（火山引擎 Ark 的 OpenAI 兼容端点）
3. 填 Key 与模型名（如豆包 `doubao-seedream-3.0`）
4. 生成底图即出真图

> 浏览器直连模式下，密钥只保存在本机 `localStorage`；用本地代理时 Key 只留在 `server/config.json`（已被 `.gitignore` 忽略），都不会上传。

## ⌨️ 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl / Cmd + Enter` | 一句话出图（顶栏输入框） |
| `Enter` | 生成底图（焦点不在输入框时） |
| `Ctrl / Cmd + Z` | 撤销 |
| `Ctrl / Cmd + Shift + Z` 或 `Ctrl / Cmd + Y` | 重做 |
| `Delete` / `Backspace` | 删除选中的图层 |
| `Esc` | 退出聚焦画布 / 关闭弹窗 |

> 改了 `styles.css` / `app.js` / `data.js` 后，记得同步升级 `index.html` 里的 `?v=YYYYMMDDx` 版本号，否则浏览器会命中旧缓存。

## 📁 目录结构

```
ai-canvas/
├── index.html              # 页面结构（三栏 + 工作台 + 设置 / 图片选择弹窗）
├── styles.css              # 玻璃拟态浅色主题（含暗色变量）
├── app.js                  # 主逻辑：素材中心、拖拽画布、提示词、出图、导出、设置、图片弹窗
├── workbench.js            # 节点式无限工作台（多画板 / 缩放平移 / 节点连线 / 自动保存）
├── data.js                 # 素材库：368 风格 + 170 排版 + 36 配色 + 14 字体（build_assets.py 生成）
├── build_assets.py         # 从 handraw-style 抓取并打包原图 + 提示词到本地
├── assets/                 # 574 张 webp 原图（风格 / 排版 / 配色），约 33MB
├── server/
│   ├── ai_proxy.py         # 本地出图代理（免 CORS、Key 留服务端、参考图进模型）
│   ├── config.example.json # 配置样例；复制为 config.json 后修改
│   └── workflows/          # ComfyUI 工作流模板（txt2img 等）
├── tools/                  # 8 套无头回归测试
├── 启动预览.command          # 一键起 8123 网页 + 9004 代理
├── 停止预览.command          # 两个一起停
├── 启动出图代理.command / 停止出图代理.command
├── 交接说明.md              # 给接手者的详细说明（架构、代理、工作台、测试）
└── README.md
```

## ⚠️ 已知边界（诚实说明）

- **角色一致性非 100%**：参考图注入约 80–85% 一致性，依赖所选模型的参考能力，极端角度可能漂移。这是当前生图能力的物理上限，非 bug。
- **ComfyUI 仅预留**：`server/workflows/` 提供模板位与 `{{REF_IMAGE}}` 约定，真实 IPAdapter / ControlNet 节点需按你的 ComfyUI 环境自备工作流。
- **OCR / TTS 未集成**：图片转文字、文案转语音仍在规划中。
- `assets/` 为约 33MB 二进制图片，已直接纳入 git；如想更干净的仓库历史，可改用 **Git LFS**。
